# copilot-instructions.md と AGENTS.md の参照ルール・メモ

## 参照メカニズム

両ファイルとも GitHub Copilot の Instruction sources として**自動的に読み込まれる**。

```
Instruction sources（.github/instructions/copilot-cli-ref.instructions.md より）:
- `.github/copilot-instructions.md`
- `AGENTS.md` (in git root and cwd)
```

→ **優先度の問題ではなく、両方が全ての会話で同時にコンテキストに注入される。**

## 役割分担

| ファイル | 行数 | 役割 |
|---------|------|------|
| `.github/copilot-instructions.md` | ~77行 | プロジェクト共通ルールの**要約**（「何をすべきか」） |
| `AGENTS.md` | ~1,439行 | 詳細な実装ガイド・コード例付き（「どう実装するか」） |

- `copilot-instructions.md` はコンテキストウィンドウの消費が少なく、全会話で即座にルールを適用するための要約
- `AGENTS.md` は実装時の詳細リファレンス（コード例・チェックリスト・フロー定義）
- 内容は「要約 ⊂ 詳細」の包含関係。矛盾は存在しない

- 現状は矛盾なし（2026-04-02 確認済）

## 結論

**変更不要。** 現在の構成は適切。両ファイルは自動参照され、要約↔詳細の関係で補完し合っている。
